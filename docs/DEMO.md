# Demonstrate and explain this project

1. Open the demo in offline mode. Choose Customers with no orders and run the previewed SQL. Expected customer: Rohan.
2. Choose Revenue by region and explain the join, GROUP BY and aggregation.
3. Edit the query to SELECT COUNT(*) AS total FROM customers; run it. The fictional dataset has four customers.
4. Attempt DELETE FROM orders. It must be refused. Read-only permissions, authorizer, parsing and deadlines provide different safeguards.
5. Own-question generation needs an enabled compatible provider plus operator token. It produces a preview only; inspect it before choosing Run query.

Explain: LEFT JOIN/NULL, SQL injection versus unsafe generated SQL, schema grounding, execution limits, read-only database permissions, and why30 reference SQL fixtures do not measure LLM accuracy.
